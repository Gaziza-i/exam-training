# Парсер открытого банка ФИПИ

`fipi_scraper.py` — скрипт на **Playwright** (headless Chromium, чтобы сайт
не отличал его от обычного браузера) + BeautifulSoup, который вытаскивает
реальные тексты заданий из `ege.fipi.ru/bank/`.

## Важное ограничение: ответов в выгрузке нет

Сайт **не публикует правильные ответы** в HTML. Кнопка «Ответить» шлёт
ваш ответ на сервер и получает в ответ только «верно/неверно» — без
текста самого правильного ответа (защита от списывания). Поэтому в
выгруженном JSON поле `correct_answer` всегда пустое.

**Что делать дальше:** пришлите получившийся JSON-файл (или его часть)
в чат — правильные ответы к настоящим формулировкам ФИПИ можно дозаполнить
вручную/через ИИ, после чего файл готов для `import_fipi`.

## Быстрый старт (Windows: используйте `py` вместо `python`, если `python`
## у вас указывает на заглушку Microsoft Store)

```bash
pip install -r requirements.txt
playwright install chromium   # скачивает сам браузер, ~150-300 МБ, один раз

# 1. Откройте https://ege.fipi.ru/bank/, выберите предмет, скопируйте proj из URL
# 2. Запустите (10 заданий на странице, --max-pages 3 = 30 заданий)
python fipi_scraper.py --proj <GUID> --subject rus --out tasks_rus.json --max-pages 3

# Хотите своими глазами увидеть, что происходит в браузере — добавьте --show-browser
# Что-то не так — добавьте --debug-dump, HTML страниц сохранится в fipi_dump/

# 3. Пришлите tasks_rus.json в чат — дозаполню correct_answer

# 4. Когда файл с ответами готов — загрузите в базу
cd .. && python manage.py import_fipi scripts/tasks_rus.json --subject rus
```
