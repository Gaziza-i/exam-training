# 🎓 Умный тренажёр для ЕГЭ

Веб-приложение для подготовки к ЕГЭ по русскому языку и базовой математике:
тренировка по темам, статистика сильных/слабых сторон, режим «вариант на
время» и тренажёр сочинения с чек-листом критериев К1–К12.

Проект полностью бесплатен в размещении: бэкенд — Render/PythonAnywhere
(free-план), фронтенд — Netlify/GitHub Pages, база данных — SQLite.

## Архитектура

```
├── backend/     Django REST Framework — задания, попытки, статистика, варианты
│   └── exam/    основное приложение (models, API, импорт из ФИПИ, демо-данные)
└── frontend/    React + Tailwind (Vite) — интерфейс
```

- **Фронтенд:** React + React Router + Tailwind CSS v4, сборка Vite.
- **Бэкенд:** Django 5 + Django REST Framework, SQLite.
- **Источник заданий:** открытый банк ФИПИ. Из коробки в проекте есть
  небольшой набор демо-заданий (помечены `source: "seed"`) — этого достаточно,
  чтобы сразу попробовать все режимы. Реальные задания из банка ФИПИ
  подключаются через `python manage.py import_fipi` — см. раздел
  [«Загрузка заданий из ФИПИ»](#загрузка-заданий-из-фипи).

## Возможности (MVP)

- 📚 Тренировка по темам (номерам заданий КИМ) с мгновенной проверкой ответа.
- 📊 Статистика: точность по каждой теме, слабые и сильные темы.
- ⏱ Режим «вариант на время» — случайный вариант по всем темам предмета с
  таймером (как на настоящем экзамене) и подсчётом результата.
- ✍️ Тренажёр сочинения — текстовый редактор + самопроверка по чек-листу
  критериев К1–К12, сохранение черновика.
- Только русский язык и базовая математика (см. «Что дальше» ниже).

## Быстрый старт (локально)

### Бэкенд

```bash
cd backend
python3 -m venv venv && source venv/bin/activate   # опционально, но рекомендуется
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # наполняет базу темами ЕГЭ и демо-заданиями
python manage.py createsuperuser  # опционально, для доступа к /admin/
python manage.py runserver
```

API поднимется на `http://127.0.0.1:8000/api/`.

### Фронтенд

```bash
cd frontend
npm install
cp .env.example .env   # при необходимости поменяйте VITE_API_URL
npm run dev
```

Приложение — на `http://127.0.0.1:5173/`.

## Загрузка заданий из ФИПИ

ФИПИ не публикует официальный API, поэтому задания нужно получить парсером и
передать в приложение в виде JSON. Формат и подробности — в
[`backend/exam/services/fipi_import.py`](backend/exam/services/fipi_import.py).

В [`backend/scripts/fipi_scraper.py`](backend/scripts/fipi_scraper.py) есть
черновик такого парсера на requests + BeautifulSoup (см.
[`backend/scripts/README.md`](backend/scripts/README.md) — он ещё не
проверен на реальной странице сайта и почти наверняка потребует правки
селекторов под её текущую вёрстку).

```bash
python manage.py import_fipi path/to/rus_tasks.json --subject rus
python manage.py import_fipi path/to/math_tasks.json --subject math_base
```

Пока парсер не подключён, приложение полностью работает на демо-данных —
ничего в моделях/API/фронтенде менять не придётся, реальные задания просто
добавятся поверх демо-набора.

> Список тем (`seed_demo.py`) составлен по типовой структуре КИМ ЕГЭ и может
> отличаться от актуальной спецификации текущего года — перед серьёзной
> подготовкой сверьте номера и формулировки тем с официальной спецификацией
> ФИПИ на fipi.ru.

## Деплой бесплатно

### Бэкенд — Render.com

1. Зарегистрируйтесь на [render.com](https://render.com), подключите репозиторий.
2. Render подхватит `render.yaml` в корне репозитория (Blueprint) — либо
   создайте Web Service вручную: root directory `backend`, build command
   `./build.sh`, start command `gunicorn config.wsgi:application`, план Free.
3. После первого деплоя скопируйте URL бэкенда (`https://xxx.onrender.com`)
   и добавьте домен фронтенда в переменную окружения `CORS_ALLOWED_ORIGINS`.

Альтернатива — **PythonAnywhere** (тоже бесплатный план): загрузите код,
настройте WSGI на `config.wsgi.application`, выполните `migrate` и `seed_demo`
в консоли.

### Фронтенд — Netlify

1. Зарегистрируйтесь на [netlify.com](https://netlify.com), подключите репозиторий.
2. Netlify подхватит `netlify.toml` (base `frontend`, build `npm run build`,
   publish `dist`).
3. В настройках сайта добавьте переменную окружения `VITE_API_URL`, например
   `https://ege-trainer-backend.onrender.com/api`.

Альтернатива — **GitHub Pages**: соберите фронтенд командой `npm run build`
в `frontend/dist` и опубликуйте эту папку через Actions/`gh-pages`; учтите,
что для GitHub Pages `VITE_API_URL` нужно задать на этапе сборки (env в CI),
так как страницы отдаются статически без серверных переменных окружения.

Free-планы Render «засыпают» после периода неактивности — первый запрос
после паузы может занять ~30–60 секунд, это нормально для бесплатного хостинга.
